# 浮译

浮译把这部手机正在播放的视频、音乐或游戏声音听写成文字，并显示简体中文。字幕浮在其他应用上面。

它使用 Android 10 及以上的系统播放捕获，标准使用不需要 root。播放器可以拒绝被采集，受保护内容也可能没有声音。本应用不会因此去绕过这些限制。

## 开始之前

- 系统：Android 10（`minSdk` 29）及以上。`targetSdk` / `compileSdk` 为 36。
- 权限：悬浮窗、麦克风（系统用这项开放播放捕获）、通知，以及开始时的屏幕捕获授权。权限和 root 的关系见 [使用指南](docs/使用指南.md#系统要求和权限)。
- 账号：识别和翻译各选一家，并填写那一家要求的密钥。密钥保存在本机加密配置里。应用不代付，也不查询余额。

## 第一次使用

1. 安装自己构建的 debug 包，按向导允许悬浮窗、录音和通知。
2. 在设置里选择识别服务商和翻译服务商，保存密钥，并选择来源语言。字段说明见 [云服务商](docs/云服务商.md)。
3. 回到主页点「开始内录」，在系统页上授予屏幕捕获。
4. 切到正在播放的应用。折叠的悬浮层保留最近定稿的一对和当前一对；点字幕区域展开更早的句子。拖动只能从「按住拖动」开始。
5. 主页的「暂停翻译」和通知里的「停止翻译」都只暂停，内录授权还在。主页的「结束本次内录」和悬浮层上的「停止」会结束授权，下次要重新授予。

完整步骤、字幕窗口和快捷设置开关见 [使用指南](docs/使用指南.md)。
