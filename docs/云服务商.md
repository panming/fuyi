识别和翻译分开选择。下面的示例值都是假的，不能拿去请求，也不能写进 issue。价格不在这里抄录；开通后的费用由你自己的账号承担，应用不代付，也不查询余额。

## 共同规则

- 目标语言固定为简体中文。没有目标语言开关。
- 来源语言以设置里的列表为准。不支持的组合会在设置页用中文说明，并拒绝改成另一种语言。
- 没有覆盖全部语种的自动识别时，应用直接报错，不会静默改成普通话、英语或中文。
- 识别失败或翻译失败后，音频和文本都不会改发给另一家。
- 自定义地址只有在你填写、选中并保存之后才会收到数据。费用算在那个地址所属的账号上。
- 还没有用这些服务商的真实账号做端到端验证。下面是代码里的请求形状，不是实测通过的承诺。

## 火山引擎

控制台产品名在向导里写的是「豆包流式语音识别模型 2.0」和「豆包机器翻译模型」。向导同时写明：不需要 IAM，也不要去开通按分钟计费的「实时语音翻译」。

| 项目 | 识别 | 翻译 |
| --- | --- | --- |
| 设置芯片 | 火山 | 火山 |
| 必需凭据 | 「豆包语音 API Key」。旧版可以改填「旧版 App ID」和「旧版 Access Token」，两项要同时有。 | 「豆包语音 API Key」，或可空的「翻译 API Key」。翻译 Key 留空时用识别那把。也可以用上面的旧版 App ID 与 Access Token。 |
| 请求头 | `X-Api-Key`。走旧版字段时改为 `X-Api-App-Key`、`X-Api-App-Id` 和 `X-Api-Access-Key`。 | 同一套。翻译资源 ID 固定为 `volc.speech.mt`。 |
| 默认地址 | 来源语言是中文或英语：`wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async`。自动识别和其它锁定语言：`wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_nostream`。 | `POST https://openspeech.bytedance.com/api/v3/machine_translation/matx_translate` |
| 模型 / 资源 | 请求里的 `model_name` 是 `bigmodel`。Resource ID 留空时是 `volc.seedasr.sauc.duration`。 | `target_language` 为 `zh`。自动识别时不传 `source_language`。 |

高级项在「旧版密钥和接口地址」里，默认收起：

- 「Resource ID（可空）」
- 「WebSocket 地址（可空，wss://）」

地址只要填写了，就必须以 `wss://` 开头，并取代上面的默认地址。设置页会显示「当前会连接」的实际地址。留空才按语言选择官方地址。

中文和英语走低延迟的 `bigmodel_async`，并打开 `enable_lid`。自动识别走句末接口，并打开 `enable_auto_lang`。其它锁定语言也走句末接口，在音频参数里带上语言代码，例如 `ja-JP`。句末模式要等一句结束才出字，所以会比中英低延迟模式慢。这不是翻译服务的超时。

设置页没有火山引擎 IAM 的 Access Key 输入框。正在使用的翻译实现也不调用 `translate.volcengineapi.com` 的 `TranslateText`。仓库里的 `VolcengineSigner` 只被单元测试用来核对一段假签名。如果错误里出现 `TranslateText`，先确认手机上的包是这次源码构建的，而不是另一份旧安装包。

假值示例，不能用于请求：

```text
豆包语音 API Key：example-volc-api-key
翻译 API Key：留空
WebSocket 地址：留空
```

- API Key：<https://docs.volcengine.com/docs/doubao-voice/api-key-usage>

## 阿里云

识别和翻译用两套不同的凭据。

| 项目 | 识别 | 翻译 |
| --- | --- | --- |
| 设置芯片 | 阿里 | 阿里 |
| 必需凭据 | 「DashScope API Key」 | 「AccessKey ID」和「AccessKey Secret」。这是 RAM 密钥。 |
| 可空字段 | 「业务空间 ID（可空）」。只允许字母、数字、下划线和短横线。 | 无 |
| 默认地址 | `wss://dashscope.aliyuncs.com/api-ws/v1/inference` | `POST https://mt.cn-hangzhou.aliyuncs.com/` |
| 模型 / 接口 | `paraformer-realtime-v2`，请求头 `Authorization: Bearer` | `Action=TranslateGeneral`，版本 `2018-10-12`，目标 `zh` |

填写业务空间 ID 之后，识别地址变为 `wss://{空间}.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference`。百炼 API Key 不会被拿去调用机器翻译，RAM 密钥也不会被拿去调用识别。

自动识别时不传 `language_hints`。锁定语言只有 `zh`、`en`、`ja`、`yue`、`ko`、`de`、`fr`、`ru` 会发送。其它锁定语言在设置页报错，开始按钮不会进入捕获。

翻译在自动识别时发送 `SourceLanguage=auto`。粤语、菲律宾语、波兰语、荷兰语、乌克兰语、罗马尼亚语、希腊语、孟加拉语、尼泊尔语没有配置翻译代码，设置页会说明，并不会改成中文或英语。

## 腾讯云

识别，以及两种翻译，是三条不同的路径。

### 识别

| 项目 | 内容 |
| --- | --- |
| 必需字段 | 「APPID」「SecretId」「SecretKey」 |
| 可空字段 | 「引擎（可空，如 16k_zh_en）」 |
| 地址 | `wss://asr.cloud.tencent.com/asr/v2/{APPID}` |
| 音频 | 16 kHz、16 bit、单声道 PCM。结束时发送文本 `{"type":"end"}`。 |

APPID 必须是 4 到 20 位数字。SecretId / SecretKey 来自 API 密钥管理。设置页写明它不是豆包 API Key。

签名把除 `signature` 以外的参数按字典序拼进原文，HMAC-SHA1 后 Base64，再对签名做 URL 编码。`slice_type` 为 0 或 1 时当作未定稿，为 2 时当作一句结束。`code` 非 0 时显示服务端 `message`。

引擎留空时按下表选择。自动识别不会被改成 `16k_zh`。俄语、意大利语、波兰语、荷兰语、乌克兰语、罗马尼亚语、希腊语、孟加拉语、尼泊尔语没有单独引擎，留空就会报错。

| 来源语言 | 留空时的引擎 |
| --- | --- |
| 中文 | `16k_zh` |
| 英语 | `16k_en` |
| 日语 | `16k_ja` |
| 韩语 | `16k_ko` |
| 粤语 | `16k_yue` |
| 西班牙语 | `16k_es` |
| 法语 | `16k_fr` |
| 德语 | `16k_de` |
| 葡萄牙语 | `16k_pt` |
| 越南语 | `16k_vi` |
| 泰语 | `16k_th` |
| 印尼语 | `16k_id` |
| 马来语 | `16k_ms` |
| 菲律宾语 | `16k_fil` |
| 阿拉伯语 | `16k_ar` |
| 土耳其语 | `16k_tr` |

自己填写引擎时，只能是下面这些名字，否则设置页报错：`Hy-ASR-3.0-preview`、`16k_zh_en`、`16k_multi_lang`、`16k_zh`、`16k_zh-TW`、`16k_yue`、`16k_en`、`16k_en_large`、`16k_ko`、`16k_ja`、`16k_th`、`16k_id`、`16k_vi`、`16k_ms`、`16k_fil`、`16k_pt`、`16k_tr`、`16k_ar`、`16k_es`、`16k_hi`、`16k_fr`、`16k_de`。

`16k_zh_en`、`16k_multi_lang` 和 `Hy-ASR-3.0-preview` 都不会自动替你选上。设置页对后两个的说明是：`16k_multi_lang` 不含中文；`Hy-ASR-3.0-preview` 单次大约 5 分钟。语言列表里没有印地语，不能从列表选出 `16k_hi`。

未接入 `wss://asr.cloud-rtc.com`。

### 翻译：TokenHub 和旧 TextTranslate

「TokenHub API Key（推荐）」一旦填写，文本只发到 `https://tokenhub.tencentmaas.com/v1/api/translations`，请求头是 `Authorization: Bearer`。这时不再调用旧的 TextTranslate，即使下面仍留着 SecretId / SecretKey。

| 项目 | TokenHub | 旧 TextTranslate |
| --- | --- | --- |
| 何时使用 | TokenHub API Key 非空 | TokenHub API Key 为空，且 SecretId、SecretKey 都有 |
| 地址 | 上面的 translations 接口 | `POST https://tmt.tencentcloudapi.com/` |
| 模型 | 「模型」留空时发送 `hy-mt2-plus`。填写的字符串会原样发送，例如 `hy-mt2-pro` 或 `hy-mt2-lite`。应用不另做模型名单校验。 | Action `TextTranslate`，Version `2018-03-21`，地域 `ap-beijing`，TC3 签名 |

## OpenAI 兼容

这项只能做翻译，不能做识别。识别芯片里没有它。如果旧配置把识别也存成了 OpenAI，开始时会提示：「OpenAI 兼容接口只用于文本翻译，不能当作流式语音识别。请另选识别服务商。」

| 字段 | 要求 |
| --- | --- |
| 地址（https://） | 必须以 `https://` 开头 |
| 模型名 | 必填。没有填写时，报错举例写了 `gpt-4o-mini`。字段不会预填模型。 |
| API Key | 必填，放在 `Authorization: Bearer` |

路径按保存的地址拼接：

| 你填写的假地址 | 实际请求 |
| --- | --- |
| `https://example.com/v1` | `https://example.com/v1/chat/completions` |
| `https://example.com/v1/` | 同上，末尾斜杠会先去掉 |
| `https://example.com/chat/completions` | 原样使用 |
| `https://example.com/openai` | `https://example.com/openai/v1/chat/completions` |

正文含 `model`、`temperature` 为 0，以及两条 message。系统提示要求译成简体中文，并在你锁定了来源语言时写上这个选择。译文取 `choices[0].message.content`。待译文本最长发送 4000 个字符。不发送音频。

这只实现了 chat completions 这一段。不能把它理解成任意服务商都兼容，也不能把它当成语音识别。腾讯云 TokenHub 的对话式调用可以用基址 `https://tokenhub.tencentmaas.com/v1`，那会拼成 `/v1/chat/completions`。翻译芯片选「腾讯」并填写 TokenHub API Key 时，走的是另一条 `/v1/api/translations`，两处不要填混。

协议参考：<https://developers.openai.com/api/reference/resources/chat>

费用由你填写的地址所属账号承担。本应用不查询该账号的余额。

假值示例，不能用于请求：

```text
地址：https://example.com/v1
模型名：example-model
API Key：example-openai-compatible-key
```
