## 系统要求和权限

应用要求 Android 10 及以上。播放捕获使用系统的 `AudioPlaybackCapture`，清单里没有 root 权限。标准支持场景不要求 root。

能采集的播放用途是媒体、游戏、未知、提示音和无障碍。通话用途不在采集范围内。本仓库不说明如何采集通话或聊天，也不说明如何绕过播放器自己关闭的捕获。

播放器可以把 `allowAudioPlaybackCapture` 设为不允许，系统也可以不把受保护内容送出来。这时电平可能一直很低，字幕不出现。这是系统限制，不是还缺一个开关。

开始一次内录时，系统仍会要求屏幕捕获授权，并显示「正在捕获屏幕」一类提示。服务会挂一个 64×64 的虚拟显示，用来维持这次捕获；画面不写入文件，也不上传。提示由系统显示，应用没有隐藏它的开关。

向导和主页会用到这些权限：

| 权限 | 应用里怎么用 |
| --- | --- |
| 悬浮窗 | 把字幕画在其他应用上。没有允许时，主页会打开系统悬浮窗设置。 |
| 麦克风 | Android 把播放捕获算进这项权限。录音器只配置了播放捕获，没有使用麦克风音源。 |
| 通知 | Android 13 及以上需要它，才能显示前台服务通知。 |
| 屏幕捕获 | 每次新的内录都要授权。暂停不会丢掉这次授权；结束后要重新授权。 |
| 忽略电池优化 | 只在向导里提供入口。不忽略也能用，切到后台后更容易被系统清掉。 |

## 安装

仓库还没有 Release，也没有预编译 APK。构建步骤、JDK / SDK 版本和 debug 签名见 [开发与贡献](开发与贡献.md#构建环境)。

包名是 `com.fanyi.overlay`，当前 `versionName` 是 `0.1.0`，`versionCode` 是 `2`。debug 包用本机调试证书签名。正式包使用另一张发布证书，证书本身不在仓库里。同一包名下，签名不同就不能覆盖安装；`versionCode` 比手机上已有的包更低时，系统也会拒绝。先在设置里记下或导出你还需要的配置，再卸载旧包。卸载会清掉已经保存在手机里的密钥。

## 向导

第一次打开、并且还没把「准备完成」写入配置时，会看到 6 步向导。完成后没有菜单可以重新进入向导。

1. 说明应用听的是这部手机正在播放的媒体声。
2. 允许悬浮窗。按钮在系统设置返回并显示「已允许」之后才能继续。ColorOS 上这项有时叫「悬浮窗」。
3. 授予录音和通知。两项都允许才能继续。
4. ColorOS / OnePlus 的补充说明：应用详情里的「后台弹出界面」、电池里的后台或忽略优化、以及自启动。自启动打不开时，按钮会退回应用详情。这一步不检查你是否真的改了系统设置，可以看过之后继续。其它品牌没有单独的菜单说明。
5. 可以粘贴豆包语音 API Key，也可以点「稍后在设置里填写」。这里只保存这一把 Key。
6. 点「进入浮译」。下一步是主页上的「开始内录」，系统会弹出屏幕捕获。Android 14 及以上使用默认显示器的捕获配置，更早版本使用系统的屏幕捕获页。向导写的是选择整个屏幕。

## 设置里实际有的字段

主页按钮是「设置密钥和悬浮层」。修改后要点「保存」，草稿才会写入加密配置。

识别服务商只有三枚芯片：「火山」「阿里」「腾讯」。没有 OpenAI 识别芯片。翻译服务商是这三家，再加上「OpenAI 兼容」。两边可以不同。只有选中的翻译服务会收到文本；失败后不会改发给另一家。

来源语言是一个列表，默认「自动识别」。可选语言和各家是否接受，见 [云服务商](云服务商.md#来源语言)。

密钥默认遮住。点「显示密钥」后在屏幕上明文显示，再点「隐藏密钥」恢复遮挡。

悬浮层只有两个滑杆：

- 不透明度，45% 到 100%，默认 88%。
- 字号，12 sp 到 22 sp，默认 15 sp。

没有单独的「换行开关」「历史开关」或「锁定窗口」开关。换行、展开和拖动是固定行为，见下一节。

「测试翻译一句 Hello」会先保存当前草稿，再只向当前翻译服务发送文本 `Hello`。成功时显示「翻译成功：」和译文。它不发送音频，也不能用来确认识别是否可用。

设置页会用红字写出当前缺的字段或不支持的语言。识别条件不满足时，主页点「开始内录」只会弹出说明，不会进入捕获。翻译还没配好时仍可以开始听写，主页有一条提示：「还没填写可用的翻译密钥。火山引擎填豆包语音 API Key 即可；阿里云仍要翻译 AccessKey。可以先听写。」

## 一次内录

1. 主页点「开始内录」。
2. 授予屏幕捕获。拒绝时提示「没有授予屏幕捕获，内录没有开始。」
3. 状态变为「内录中」，悬浮层出现。主页上的色条是播放音量电平，不是进度。
4. 切到视频、音乐或游戏。原文出来后，短暂停顿再请求翻译。
5. 暂停或结束，见下表。

| 位置 | 文案 | 实际作用 |
| --- | --- | --- |
| 主页 | 开始内录 | 检查识别配置和权限，然后请求屏幕捕获。 |
| 主页 | 暂停翻译 | 停止听写，保留这次捕获授权和已经出现的字幕。 |
| 主页 | 继续翻译 | 用现有授权重新连接识别，不再弹出捕获页。 |
| 主页 | 结束本次内录 | 停止服务、关掉悬浮层、释放捕获授权。下次要重新授权。只在进行中或暂停时出现。 |
| 通知 | 停止翻译 | 和主页的暂停相同，不是结束授权。通知标题变为「浮译已暂停」。 |
| 通知 | 开始翻译 | 从暂停继续。通知说明授权还在，不用重新授权。 |
| 悬浮层 | 停止 | 结束本次内录，释放捕获授权。和通知里的「停止翻译」不同。 |
| 悬浮层 | 继续 | 从暂停继续。 |
| 悬浮层 | 开始 | 尚未开始时尝试打开主页并走「开始内录」。若系统拦住后台打开，请从通知回到应用，或在 ColorOS 允许「后台弹出界面」。 |
| 快捷设置 | 浮译 | 需要自己把磁贴加到快捷设置。进行中时副标题是「翻译中」，点击会暂停；暂停时副标题是「已暂停」，点击会继续；没有会话时点击会打开授权流程。 |

点通知正文会打开主页，不会暂停或结束。

暂停期间，识别连接会断开，悬浮层更透明，并显示「已暂停」。字幕留在内存里。结束或开始新的一次内录时，内存中的字幕会清掉。

如果在听的过程中修改并保存了识别服务商、来源语言、火山引擎地址、Resource ID、腾讯云引擎或阿里云业务空间，正在进行的识别会按新配置重新连接。只改密钥不会触发这次重连；暂停后再继续，或结束再开始，才会带上新密钥。

## 字幕窗口

悬浮层宽度不超过屏幕两侧各 16 dp 之后的剩余宽度，也不超过 420 dp。默认出现在屏幕偏下的位置。只有顶部的「按住拖动」能移动窗口，松手后位置写入配置。字幕区域的点按不移动窗口。

折叠时只保留两对：上一对定稿，和当前这一对。当前这一对可能还是实时片段。还没有字幕时，折叠窗口显示「正在听…」。

点字幕区域在折叠和展开之间切换。展开后显示本次内存里的句子，最多保留 40 句定稿，再加上正在听的片段。折叠时字幕区域最高 320 dp，展开时最高 480 dp。超过之后在区域内滚动，并自动滚到最新一句。长句自动换行，没有单独开关。

主页「最近字幕」另有一份列表：最新的在上面，最多 6 句，并单独显示标成「实时」的未定稿。主页列表和悬浮层是同一份内存数据。

判定为中文的句子不再请求翻译。主页译文行写「中文，未再翻译」。悬浮层的译文行会再显示一遍原文。来源语言选「中文」或「粤语」时一律这样处理。选「自动识别」时，由识别返回的中文语种标签，或文字里汉字占比很高，也会跳过翻译。选了其它锁定语言时，即使文字看起来像中文，仍会送去翻译。

翻译失败时，主页用红字显示原因。悬浮层把原因写在译文那一行。识别连接本身失败时，状态变为「出错了」，并结束本次内录。

## 快捷设置和通知文案

通知渠道名是「内录翻译」。进行中的标题是「浮译正在翻译本机播放的声音」，说明是「系统会显示屏幕捕获提示。应用不保存、不上传画面。」暂停后的说明是「内录授权还在。点「开始翻译」即可继续，不用重新授权。」

服务被系统停掉时不会自动拉起。需要再点一次「开始内录」。后台被清掉的处理见 [故障排查](故障排查.md#切到后台后翻译停了)。
