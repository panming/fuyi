# 隐私与安全

这里只说明这部应用自己做什么。各家云服务商还会按他们自己的条款保留音频、文本和日志，那些规则以服务商文档为准，本应用控制不了，也不能因为「只翻译」就说成绝对安全。

## 数据经过哪里

1. 系统播放捕获取出正在播放的音频。采集用途是媒体、游戏、未知、提示音和无障碍，不含通话用途。
2. 音频在内存里重采样为 16 kHz、16 bit、单声道 PCM，大约每 200 毫秒送一块给当前选中的识别服务。识别只有火山引擎、阿里云或腾讯云三选一。
3. 原文立即显示。停顿大约 180 或 320 毫秒后，文本发给当前选中的翻译服务。OpenAI 兼容和腾讯云 TokenHub 只接收文本。
4. 失败时停止在这一家里。不会把同一段音频或文本再发给另一家。

火山引擎的自定义 `wss://`、阿里云的业务空间域名，以及 OpenAI 兼容地址，都只在你填写并选中之后使用。

为了让系统保持这次播放捕获，服务会创建一个 64×64 的虚拟显示。像素不写入文件，也不上传。系统仍会显示屏幕捕获提示，应用没有开关可以关掉这个提示。

## 手机里保存什么

密钥、服务商、来源语言、悬浮层位置、不透明度和字号写入本机的加密 `SharedPreferences`，文件名是 `fanyi_secrets`。实现使用 Jetpack Security 的 `EncryptedSharedPreferences`，主密钥是 `AES256_GCM`，键和值分别使用 `AES256_SIV` 和 `AES256_GCM`。

`allowBackup` 为 false。备份和设备迁移规则排除了全部 shared preferences。应用不会把这组配置同步到云备份。

加密存储初始化失败时，主页会显示具体错误。这种情况下密钥只留在当前进程的内存里，退出后要重填。

字幕只放在进程内存中，最多 40 句定稿。开始新的一次内录时清空。应用没有把字幕写入数据库或文件的代码。进程被杀、结束内录之后再开始，这些句子都不再保留。暂停不会清空它们。

音频块放在内存通道里送给识别客户端。仓库里没有把 PCM 写成音频文件的实现。

## 这不能叫绝对保密

加密配置可以避免其它普通应用直接读到明文，也可以避免备份带走配置。它不能阻止拿到已解锁手机的人查看：设置页有「显示密钥」。根权限、备份漏洞或同一签名的调试包也不在这种加密能保证的范围内。

放在安装包里的长期 Secret 更不合适。手机上的长期密钥只适合自己带着自己的钥匙使用。如果要做成给别人用的服务，应由你自己的后端签发短时令牌。本仓库没有这样的后端。

云服务商收到的音频和文本，保留多久、是否用于训练、日志里有什么，都要看那一家当时的条款。本应用的说明不能代替那些条款。

## 日志和反馈

代码里没有使用 Android 日志接口去打印密钥。错误仍可能带上服务端返回的一段正文，火山引擎的失败信息里还可能有 `X-Tt-Logid`，腾讯云旧翻译的失败信息里可能有 `RequestId`。这些标识不是密钥，但整段错误里仍可能夹着你不该公开的内容。

发 issue 或把错误转给别人之前：

- 删掉 API Key、SecretId、SecretKey、Access Token、Authorization 头和整段签名 URL。
- 可以保留 HTTP 状态码、服务商名称、来源语言和去掉密钥后的错误句子。
- 不要把「显示密钥」打开后的截图发出去。
