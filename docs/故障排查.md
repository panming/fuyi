# 故障排查

先看主页状态和红字，再对照下表。提交 issue 前请去掉密钥，格式见 [贡献说明](../CONTRIBUTING.md)。

[返回首页](../README.md) · [使用指南](使用指南.md) · [云服务商](云服务商.md) · [隐私与安全](隐私与安全.md)

本应用不采集通话用途，仓库里也没有绕过播放器捕获限制的步骤。下面不会提供这类做法。

## 没有声音，也没有字幕

症状：色条几乎不动，悬浮层停在「正在听…」，主页没有「实时」文本。

原因：播放捕获只接收媒体、游戏、未知、提示音和无障碍这些用途。系统静音、播放器暂停、蓝牙输出异常，或者对方应用不允许播放捕获，都会得到空音频。受保护内容也可能被系统留在本机而不送出。root 不能作为这里的解决办法，本仓库也不说明如何强制采集。

排查：

1. 确认状态是「内录中」，不是「已暂停」或「出错了」。
2. 用手机自己的扬声器播放一段普通本地或在线视频，把媒体音量打开。
3. 看主页色条是否随声音抬起。色条不动时，问题在捕获，不在翻译密钥。
4. 换一个允许系统捕获播放音频的播放器试一次。仍然没有声音，就保持这样使用；不要改系统去抓取被拒绝的音频。

## 权限或系统提示把内录拦住了

症状：点「开始内录」后出现「请先允许悬浮窗。」「需要录音权限。」或「没有授予屏幕捕获，内录没有开始。」悬浮层没出现，或提示「悬浮窗没有加上」。

原因：缺悬浮窗、麦克风或通知权限，或者屏幕捕获被拒绝。Android 14 及以上还会检查媒体投影前台服务是否成功。ColorOS 上，悬浮层里的「开始」若拉不起页面，向导提到的「后台弹出界面」可能还没开。

排查：

1. 按 [使用指南](使用指南.md#向导) 重新检查悬浮窗、录音和通知。
2. 再点「开始内录」，在系统页上完成屏幕捕获。状态栏出现捕获提示是正常的。
3. 从通知打开应用，而不是只依赖悬浮层上的「开始」。
4. 系统若自己结束捕获，主页说明会变为「系统结束了本次捕获」。需要重新开始。

## 只有原文，没有译文

症状：原文在更新，译文空白、一直是「中文，未再翻译」，或红字写着缺密钥。

原因要分开看：

- 来源语言是中文或粤语，或自动识别判定这句是中文。应用故意不再翻译，主页写「中文，未再翻译」。
- 翻译服务还缺字段。听写可以先开始，该句会标成失败，并写上缺什么。
- 「测试翻译一句 Hello」没通过。识别是好的，翻译请求本身失败。
- 句子还很短。未到句读时大约等 320 毫秒，已经有逗号、句号等句读时大约等 180 毫秒，然后才发送。更短的片段可能被跳过。

排查：把来源语言改成实际的外语并保存；在设置页看翻译服务商下面的红字；先让 Hello 测试通过。应用不会因为这家失败就去调用另一家。

## 鉴权失败，或错误里出现 TranslateText

症状：红字含「鉴权失败」、HTTP 401 / 403，或正文里有 `TranslateText`。

原因：当前火山翻译发送的是豆包机器翻译 `matx_translate`，请求头是 API Key，不是 IAM 的 `TranslateText`。设置页也没有 IAM Access Key 字段。`TranslateText` 更可能来自另一份旧安装包，或来自腾讯云旧接口 `TextTranslate` 的报错。腾讯云产品概述写明旧的文本翻译不再支持新用户，见 [云服务商](云服务商.md#翻译tokenhub-和旧-texttranslate)。

排查：

1. 确认安装的是本仓库构建的 `com.fanyi.overlay`。签名对不上时不能覆盖旧包，要先卸载再装，见 [使用指南](使用指南.md#安装)。
2. 火山引擎只填「豆包语音 API Key」，或另外一把「翻译 API Key」。不要把阿里云 RAM 密钥或腾讯云 SecretId 填进这个框。
3. 腾讯云翻译优先填 TokenHub API Key。新账号不要依赖旧的 TextTranslate。
4. 阿里云识别只填 DashScope API Key，翻译只填 RAM 的 AccessKey ID 和 Secret。

## 新旧安装包叠在一起

症状：设置页和文档对不上，没有 TokenHub 字段，或安装时提示签名冲突、版本降级。

原因：包名同为 `com.fanyi.overlay` 时，Android 只允许同一签名且 `versionCode` 不降低的覆盖安装。本仓库以前的 debug 构建是 `versionCode` 1。0.1.0 正式包是 `versionCode` 2，并且使用发布证书，不能覆盖 debug 包。

排查：先自己记下设置里的配置。卸载手机上的旧包后再安装。卸载会删除本机加密配置，密钥需要重填。不要把别的目录里的历史 APK 当作本仓库已经发布的正式包。

## 余额和语音 API Key

症状：想在应用里看剩余额度，或以为语音 API Key 就能查询账单。

原因：应用没有余额查询。豆包语音 API Key、百炼 API Key、TokenHub API Key 都只按各自的识别或翻译请求发送。配额、欠费和资源包要打开对应服务商的计费说明或账单。

入口集中在 [云服务商](云服务商.md) 各节，不在应用里。红字若包含「配额」「欠费」「资源包」或 `quota`，应用只显示这个结果，不会改用另一家。

## 网络、配额和语言报错

症状：主页变为「出错了」，或某一句译文是失败原因。

应用会把常见网络错误收成这两句：「连不上服务器。检查手机网络后再试。」「连接超时。可以再点一次开始。」其它服务端原文最多显示约 280 个字符。识别连接报错时会结束本次内录；单句翻译失败通常只标在那一句上。

语言类红字以设置页为准，例如腾讯云自动识别、阿里云不在 `language_hints` 里的锁定语言、豆包机器翻译没有短代码的孟加拉语和尼泊尔语。处理办法是改来源语言或改服务商，而不是等应用自动降级。

## 翻译显得慢

症状：中英以外的语言要等一句说完才出原文，译文又晚一点。

原因：火山引擎在中文和英语上使用低延迟地址，自动识别和其它锁定语言使用句末地址。译文还要再等大约 180 或 320 毫秒的停顿，以及所选翻译接口的网络时间。没有「加速」开关。

排查：中英内容可以把来源语言明确选成「中文」或「英语」，让识别走低延迟地址。选「中文」后将不再请求翻译。其它语言的句末等待是当前实现的行为。

## 切到后台后翻译停了

症状：锁屏、切走一段时间后通知消失，状态回到「未开始」。

原因：服务不会在进程被杀后自动重启。捕获期间有一个最长 4 小时的部分唤醒锁，它不能阻止厂商省电策略。向导里的忽略电池优化和 ColorOS 自启动是可选入口，不是保证。

排查：在系统设置里允许浮译后台活动。被清掉之后重新点「开始内录」，并再次授予屏幕捕获。暂停状态如果还在，通知会写明授权还在，点「开始翻译」即可，不必重新授权。

## 悬浮层挡住画面，或长句被截断

症状：字幕压住视频按钮，或一句很长。

原因：默认位置在屏幕偏下。折叠高度上限 320 dp，展开上限 480 dp，更长的内容在字幕区域内滚动。长句会换行。这些都没有单独的设置项。

排查：按住「按住拖动」移开窗口。字号和不透明度在设置里，范围分别是 12–22 sp 和 45%–100%。点字幕区域可以展开或收回历史。结束观看时用主页的「结束本次内录」或悬浮层的「停止」，不要只把窗口拖到一边就认为捕获已经结束。
